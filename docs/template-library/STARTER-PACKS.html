Research-control pack

Use this pack when you want the strictest possible agent behaviour before implementation:

  1. Read RESEARCH-DNA.md.
  2. Select a pattern from PROMPT-PATTERN-MATRIX.md.
  3. Apply prompts/01-master-agent-enforcement-prompt.md.
  4. Use skills/04-evidence-collection-skill.md.
  5. Enforce contracts/01-completion-honesty-contract.md.
  6. Finish with SCIENTIFIC-CONTROL-CHECKLIST.md.

Acceptance rule: no success claim is valid unless observation, decomposition, verification, reflection, and traceability are all visible.
