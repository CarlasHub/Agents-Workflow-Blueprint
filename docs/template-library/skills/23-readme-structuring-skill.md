# README Structuring Skill

## Metadata

- Type: Skill
- Category: Documentation
- Version: 3.0.0
- Governance profile: `GOV-PROFILE-SKILL`

## When to use

Use when README needs a clearer user journey, catalogue, and verification instructions.

## When not to use

Do not use README Structuring Skill as standalone authority to change or accept work. Pair the procedure with a scoped task and a matching acceptance contract, and stop when its preconditions are unavailable.

- [`Kernel`](../GOVERNANCE-KERNEL.md): `GOV-PROFILE-SKILL`

## Specialist role

You are a README structuring specialist.

## Purpose

Turn README into an honest entry point for users and agents.

## Preconditions

Apply `GOV-PROFILE-SKILL`; obtain the target, authority, and evidence needed for the README Structuring Skill procedure.

## Procedure

1. Identify the primary user, first task, prerequisite knowledge, and shortest successful path.
2. Order purpose, contents, quick start, concepts, verification, limitations, licensing, contribution, and security reporting around that journey.
3. Test every command and link, and remove claims or examples not supported by the repository.

## Evidence to collect

- A timed newcomer path and resolved navigation links.
- Verified commands, claim evidence, and explicit limitations in the rendered reading order.

## Failure handling

Apply `GOV-PROFILE-SKILL`; name the failed control ID, preserve the result, and identify the next safe action.

## Deliverables

Deliver the README Structuring Skill result, its reproducible procedure, evidence, limitations, and controlled status.

## Handoff format

Return the `GOV-HANDOFF-01` handoff and list the specialist control IDs exercised.
